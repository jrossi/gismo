{{% blocks/lead color="primary" %}}
**Stop wasting time on Claude Code debugging cycles.**

Gismo creates intelligent feedback loops that catch syntax errors, security issues, and style violations
**before** Claude Code writes invalid files. Transform your AI development from reactive debugging
to proactive validation.
{{% /blocks/lead %}}

{{< blocks/section color="dark" type="row" >}}
{{% blocks/feature icon="fa-lightning-bolt" title="Real-Time Validation" %}}
Files are analyzed instantly as Claude Code attempts to write them. Catch syntax errors, style violations, and security
issues before they become problems.
{{% /blocks/feature %}}

{{% blocks/feature icon="fa-route" title="Course Correction" %}}
Prevents Claude Code from pursuing invalid implementation paths. Smart feedback keeps AI development on track with
immediate corrections.
{{% /blocks/feature %}}

{{% blocks/feature icon="fa-shield-alt" title="Security First" %}}
Block dangerous operations and secret exposure before they happen. Multi-layered protection with configurable
security policies.
{{% /blocks/feature %}}

{{< /blocks/section >}}

{{< blocks/section type="row" >}}
{{% blocks/feature icon="fa-code" title="Multi-Language Support" %}}
Comprehensive linting for Go, Python, JavaScript, TypeScript, Markdown, JSON, Rust, and Protocol Buffers. Extensible
architecture for adding new languages.
{{% /blocks/feature %}}

{{% blocks/feature icon="fa-tachometer-alt" title="High Performance" %}}
Sub-microsecond message parsing with optimized execution. Built for speed with go-json for 2-3x faster JSON processing.
{{% /blocks/feature %}}

{{% blocks/feature icon="fa-cogs" title="Extensible Architecture" %}}
Pluggable handler system with priority-based execution. Easy to add custom validation rules and organizational policies.
{{% /blocks/feature %}}
