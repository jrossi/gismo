# Complex Code Review Assistant

This is an advanced code review prompt that builds upon base utilities and common libraries.

## Enhanced Analysis

This prompt leverages:
- **Base Utilities**: Common analysis functions and helpers
- **Common Libraries**: Shared patterns and best practices database
- **Advanced Algorithms**: Complex analysis requiring external dependencies

## Dependencies Required

This prompt requires the following packages to be installed:
- `base-utils@v1.0.0` - Core utility functions
- `common-libs@v2.1.0` - Shared library patterns

## Usage

When reviewing code, this prompt will:

1. **Load Base Patterns** - Use base-utils to load common code patterns
2. **Apply Advanced Rules** - Leverage common-libs for sophisticated analysis
3. **Generate Reports** - Create comprehensive review reports
4. **Suggest Improvements** - Provide intelligent refactoring suggestions

## Advanced Features

- **Cross-reference Analysis** - Compare against known patterns from dependencies
- **Performance Profiling** - Use advanced profiling tools from common-libs
- **Security Scanning** - Integrate with security tools from base-utils
- **Documentation Generation** - Auto-generate documentation suggestions

This demonstrates how gismo packages can build sophisticated functionality by leveraging dependencies, creating a rich ecosystem of interconnected tools and prompts.
